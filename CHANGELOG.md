# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-08-03

### Added

- Japanese and English `My Clippings.txt` parsing.
- Kindle notebook HTML parsing with selector fallbacks.
- SHA-256 de-duplication and atomic sync state.
- Searchable combined and per-book PDF generation with Japanese CID fonts.
- Notion Data Source API synchronization using API version `2026-03-11`.
- Dry-run, bounded retry, tests, CI, devcontainer, examples, and setup documentation.
